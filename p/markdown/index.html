Markdown语法

Markdown语法的简单使用笔记。

2022-06-18

Markdown语法

一级标题用：# 标题内容

多级标题

二级标题用：## 标题内容

三级标题

三级标题用：### 标题内容

以此类推，但markdown最多可有六级标题

字体

字体加粗用：**字体内容**

hello world！

字体斜体用：*字体内容*

hello world！

字体加粗且斜体用：***字体内容***

hello world！

字体删除横杠用：~~字体内容~~

hello world！

字体加下划线用：<u>hello world!</u>

hello world!

字体下标表示用：H~2~o 部分markdown不能解析，需使用 H<sub>2</sub>o

H2o

H2o

字体上标表示用：n^2^ 部分markdown不能解析，需使用 n<sup>2</sup>

n^2^

n2

字体高亮用：==字体内容== 部分markdown不能解析，需使用 <mark>hello world!</mark>

==hello world!==

hello world!

键盘符号 使用 <kbd>CTRL</kbd

CTRL

引用

引用内容用：> 内容

二级引用用：>> 内容

两次enter键跳出引用

分割线

常用的分割线用：---或者***回车即可

图片

插入本地图片用：![图片名字](图片地址绝对路径)

插入网络图片用：![图片名字](图片地址图片链接)

本地地址和网络上图片地址可能会由于本地的更改删除或者网络图片出处的删除，而导致图片无效而显示不出来，建议大家把需要的图片上传到自己创建的图床里。

超链接

超链接用：[链接名字](链接地址)

点击跳转到我的主页

自动链接用：<链接地址url或者邮箱>

https://ruheyun.github.io/

列表

有序列表用：1. 内容

  1. a
  2. b
  3. c

无序列表用：- 内容

  • a
  • b
  • c

表格

插入表格最简单方法，直接鼠标右键选插入>表格即可

名字 性别 生日

|属性|属性|属性|

|--|--|--|

|内容|内容|内容|
